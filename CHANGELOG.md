# Изменения Lulz

## 1.0.1

### Новые режимы

- Добавлен анализ локальных HAR-сессий: несколько записанных ответов, точный фильтр хоста, текстовые и base64-тела, явный учёт отсутствующего содержимого. Запросы из HAR не повторяются.
- Добавлены 19 правил конфигурации и кандидатов на секреты: Dockerfile, Kubernetes JSON, Terraform JSON, PEM private key, статические credential-поля и URL с паролем.
- Добавлен общий аудит проекта с выбором разделов source/config/secrets/dependencies и сохранением ограничений каждого раздела.
- Добавлены профили quick/full, команды har/local/project/rules и новые пункты меню.

### Зависимости

- Помимо requirements/npm добавлены Pipfile.lock, poetry.lock, uv.lock, Cargo.lock, composer.lock и go.sum.
- Поддерживаются PyPI, npm, Packagist, crates.io и Go, включая соответствующие CycloneDX package URL.
- Для Poetry/uv/Pipfile/Cargo проверяется доступная информация об источнике; workspace-пакеты и распознанные неподдерживаемые источники пропускаются. Для остальных форматов происхождение артефакта не устанавливается.
- CycloneDX PURL с qualifiers/subpath и Composer dev-версии/aliases пропускаются, без попыток угадать публичную версию.
- go.sum обозначается как инвентарь, который может включать неиспользуемые версии.

### Отчёты и CI

- Добавлен экспорт SARIF 2.1.0; JSON, HTML и Markdown сохранены.
- HTML получил локальные фильтры и поиск, без внешних ресурсов и исполнения содержимого проверяемых страниц.
- Добавлены baseline-статусы new/unchanged/updated и флаг --new-only для порогов CI. Находки не удаляются из отчёта.
- Для baseline проверяется совместимость охвата; неполные результаты и различающиеся режимы поиска бюллетеней не используются для ложного исчезновения находок.
- Расширены пассивные проверки cookies и учёт ограничений сохранённых HTTP-ответов.

### Совместимость и точность

- Минимальная версия Python повышена до 3.11 для стандартного TOML-парсера; сторонние runtime-пакеты не требуются.
- Структурный разбор YAML и Terraform HCL не заявляется: распознанные неподдерживаемые конфигурации явно отмечают неполный охват.
- Резервные копии в .lulz-backups исключаются из локального анализа.
- Добавлены регрессионные тесты для redaction, границ чтения, моделей наследования конфигурации, baseline, форматов зависимостей и HAR.

## 1.0.0

- Зелёное русскоязычное консольное меню и Windows/Linux лаунчеры.
- Пассивная проверка одного URL: HTTP-заголовки, cookies, TLS, HTML и видимые признаки раскрытия информации.
- Локальный анализ SQLi/XSS-кандидатов, динамического исполнения, десериализации и некоторых настроек в исходниках.
- Инвентаризация PyPI/npm и онлайн-сопоставление точных версий с OSV.
- JSON, HTML и Markdown, история и сравнение отчётов; исходный код под MIT.
